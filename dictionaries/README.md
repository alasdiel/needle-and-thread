# Dictionaries

The US English Hunspell dictionary the spellchecker uses, built into the app so it works
the same everywhere, including an AppImage or a Windows install with no system dictionary.

`en_US.aff` and `en_US.dic` are from SCOWL, as packaged by Debian (`hunspell-en-us`,
version 1:2020.12.07-2). Their licence, with the full list of sources, is in
`en_US-LICENSE.txt`.
